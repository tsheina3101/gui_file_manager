# Файловый менеджер с графическим интерфейсом
## Функционал:
+ Копирование файлов
+ Удаление файлов
+ Удаление папок
+ Поиск папки
+ Подсчет количества файлов внутри папки, включая вложенные
+ Добавление текущей даты к имени файла
+ Добавление текущей даты к именам всех файлов внутри папки (включая вложенные)

## Запуск приложения
Для запуска приложения необходимо запустить на выполнение файл gui_manager.py
